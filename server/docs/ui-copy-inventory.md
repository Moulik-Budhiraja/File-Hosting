## Budget

Visible copy stays only when it helps a user choose, act, recover, or understand current state. Accessibility names, status/live regions, error attribution, focus recovery, and destructive consequences remain. This pass is deletion-first and does not alter backend compatibility.

## Retained because operational

- Navigation labels, headings, control labels, current filters, counts, pagination, current visibility, meaningful owner, size/type, present tags, links, and upload time.
- Visibility-choice descriptions because they determine who can open a file.
- Specific HTTP/server-versus-network outcome distinctions for authentication, password changes, pending-key recovery, and ambiguous mutations.
- Validation errors, field association, retry/cancel controls, focus restoration, status/live-region announcements, and screen-reader-only action names.
- One-time secret copy failure recovery and acknowledgement/close protection.
- Destructive confirmation consequences for deleting files, revoking keys, disabling accounts, changing roles, and resetting passwords.
- Last-active-admin lockout explanation and recovery action.

- Restored the terse API-key consequence at password change.

- Distinguished `No files` from `No files match the current filters`.

- Reduced mobile nav padding so every active destination is fully visible at 390 px.
